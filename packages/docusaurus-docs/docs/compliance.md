# Compliance Package

## Introduction

`@mindfiredigital/adac-compliance` provides a rules‑engine to check architecture diagrams against compliance frameworks (PCI‑DSS, HIPAA, SOC‑2, etc.).

## Installation

```bash
npm install @mindfiredigital/adac-compliance
# or
pnpm add @mindfiredigital/adac-compliance
```
