# Parser & Validator Package

## Introduction

`@mindfiredigital/adac-parser` and `@mindfiredigital/adac-validator` work together to parse ADAC YAML files and validate them against the core schema.

## Installation

```bash
pnpm add @mindfiredigital/adac-parser @mindfiredigital/adac-validator
```
