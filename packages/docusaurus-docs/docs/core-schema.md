# Core Schema Package

## Introduction

`@mindfiredigital/adac-core-schema` defines the **ADAC** JSON schema and TypeScript types. It is the foundation for all other packages, ensuring a consistent model across validation, diagram generation, cost estimation, and compliance checks.

## Installation

```bash
pnpm add @mindfiredigital/adac-core-schema
```

or install the whole monorepo workspace:

```bash
pnpm install
```

## Usage

Import the schema or types in your code:

```typescript
import { ADACSchema } from '@mindfiredigital/adac-core-schema';
```

Feel free to extend or customize the schema as needed.
